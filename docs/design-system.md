# Navya Collection – Design System Document (DSD)

## 1. Objective
Create a unified visual identity for Navya Collection that reflects a modern, premium, trustworthy, and scalable fashion brand.

## 2. Brand Personality
The interface should feel premium, modern, clean, minimal, trustworthy, fast, and family-friendly.

## 3. Design Philosophy
Less Elements. Better Experience.

Core principles:
- White space
- Large product images
- Clear typography
- Simple navigation
- Smooth interactions
- Fast loading

## 4. Color System

### Primary Brand Color
- Deep Navy: `#183A73`
- Purpose: logo, navigation, primary buttons, links

### Accent Color
- Brand Orange: `#F15A25`
- Purpose: CTA buttons, sale badges, offers, highlights

### Neutral Colors
- Background: `#FAFAFA`
- Surface: `#FFFFFF`
- Primary Text: `#1E1E1E`
- Secondary Text: `#6B7280`
- Border: `#E5E7EB`
- Divider: `#F3F4F6`

### System Colors
- Success: `#22C55E`
- Warning: `#F59E0B`
- Error: `#EF4444`
- Info: `#3B82F6`

## 5. Typography
- Headings: Playfair Display
- Body: Poppins

### Font Scale
- H1: 48px
- H2: 40px
- H3: 32px
- H4: 24px
- H5: 20px
- Body Large: 18px
- Body: 16px
- Small: 14px
- Caption: 12px

## 6. Grid System
- Desktop: 12 columns
- Tablet: 8 columns
- Mobile: 4 columns

## 7. Spacing System
Base unit is 8px.
Allowed spacing values: 4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96.

## 8. Border Radius
- Small: 8px
- Medium: 12px
- Large: 16px
- Extra Large: 24px
- Pill: 999px

## 9. Shadows
- Level 1: Cards
- Level 2: Dropdown
- Level 3: Modal

## 10. Buttons
Button variants:
- Primary
- Secondary
- Outline
- Ghost
- Danger
- Success

Every button must support:
- hover state
- focus state
- disabled state
- loading state

## 11. Form Elements
Use standard rounded components with consistent spacing and clear validation messages.

## 12. Cards
Use consistent spacing and border radius across product, category, feature, testimonial, and offer cards.

## 13. Icons
Use Lucide React with outline, rounded, and consistent stroke width.

## 14. Product Images
Use 4:5 ratio, optimized high-resolution assets, and consistent background treatment.

## 15. Animations
Allowed: fade, slide, scale, hover lift, skeleton loading.
Avoid excessive motion.

## 16. Responsive Breakpoints
- Mobile: 0–639px
- Tablet: 640–1023px
- Laptop: 1024–1279px
- Desktop: 1280px+
- Large Desktop: 1536px+

## 17. Accessibility
- High color contrast
- Keyboard navigation
- Focus indicators
- Semantic HTML
- Alt text for images

## 18. UI Consistency Rules
- Use design tokens for colors and spacing.
- Reuse components instead of creating duplicates.
- Keep consistent icon sizing.
- Maintain equal spacing across sections.
- Use one primary CTA per screen.

## 19. Future Ready
The design system should support dark mode, seasonal themes, festival campaigns, mobile app growth, and admin dashboards without redesigning the core UI.
