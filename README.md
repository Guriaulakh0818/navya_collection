# Navya Collection

A Next.js + TypeScript + Tailwind CSS ecommerce frontend foundation for Navya Collection.

## Tech Stack
- Next.js
- TypeScript
- Tailwind CSS
- Prisma ORM
- PostgreSQL (Supabase)
- Razorpay
- Shiprocket
- Cloudinary
- MSG91

## Architecture Summary
The project follows a modular, feature-first structure with clear separation between public, customer, checkout, admin, and shared modules.

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
